# Windows 95 UI Kit

Source: [Windows 95 UI Kit (Community)](https://www.figma.com/design/zejlPpXIKZbyEUIBmm7Oir/Windows-95-UI-Kit--Community-?node-id=1-3230).

## Содержимое

- **99 компонентов**: каждый отдельно в SVG и PNG.
- **21 справочный лист и образец цвета**: SVG и PNG в `references/`.
- `index.html` — локальный каталог компонентов с просмотром и ссылками на файлы.
- `preview.png` — общий контактный лист.
- `manifest.json` — исходные ID Figma, названия, размеры, пути и SHA-256 файлов.
- `palette.json` — семь цветов из набора.
- `_source/` — полный SVG страницы Components и восемь отдельных SVG-листов Figma.
- `../windows95-ui-kit.zip` — архив всего комплекта.

Компоненты сгруппированы в папках `button`, `number-input`, `input-field`,
`radiobutton`, `checkbox`, `control-button`, `window-frame`, `titlebar`,
`icons`, `navbar`, `label`. ID в имени файла предотвращает совпадения названий.

## Экспорт

Исходные SVG получены через Figma MCP. Компоненты выделены из SVG по именам
слоёв и координатам из Plugin API, без фона листа и служебных рамок таблиц.
Сохранены только необходимые фильтры, маски и встроенные изображения.
PNG созданы локально в Chromium из отдельных SVG в исходных размерах компонентов;
это не растровые вырезки из общего скриншота.

Figma ограничила экспорт всей страницы шириной 4096. Для восьми листов сохранены
также отдельные экспорты 1:1. Остальные элементы выделены из полного векторного
экспорта и возвращены к исходным размерам; возможна погрешность округления
координат Figma. Растровые иконки внутри SVG сохранены в исходном виде.

Набор включает все 99 мастер-компонентов и их объявленные варианты состояний.
Демонстрационные комбинации boolean-параметров, например окно без statusbar,
также сохранены на справочных листах, но не выделены как дополнительные компоненты.

## Godot

Для игровых текстур используйте **PNG**: SVG набора содержит SVG-фильтры и
растровые заливки, которые импорт SVG в Godot поддерживает не полностью.
PNG сохраняет внешний вид и прозрачность иконок.

- `texture_filter = Nearest` для пиксельного вида.
- Увеличение в целое число раз сохраняет пиксельную сетку.
- Текст на кнопках и в окнах уже входит в изображения. Для интерактивных элементов
  используйте их как визуальные образцы и отдельные игровые Label.
- Растягиваемые рамки потребуют настройки NinePatchRect/StyleBoxTexture;
  готовая тема Godot в этот экспорт не входит.

`.gdignore` исключает исходные листы и справочные изображения из импорта Godot.

## Повторная сборка и проверка

Из корня репозитория, Python 3 + Microsoft Edge, без дополнительных пакетов:

```powershell
python tools/figma/export_windows95.py
python tools/figma/export_windows95.py --verify
```

Скрипт использует сохранённые исходники, новые вызовы Figma MCP не нужны.
Проверяет уникальность ID, контрольные суммы, ссылки SVG, декодирование PNG,
наличие видимых пикселей и прозрачность иконок.
